# VOID LEADS

Персональная система поиска потенциальных клиентов: Public Hunter, VK/RSS, импорт CSV, CRM, Windows UI.

## Статус

⚠️ В репозитории настроен GitHub Actions для сборки установщика, но **исходный код приложения ещё не загружен**. Пока сборку запускать рано.

## Первая публикация исходников

1. Скачайте [архив проекта v0.4.0](https://chatgpt.com/) из разговора ChatGPT, распакуйте папку `void-leads`.
2. Откройте [загрузку файлов в GitHub](https://github.com/kazakavtobus/void-leads/upload/main).
3. Перетащите **содержимое** папки `void-leads` (не сам ZIP и не внешнюю папку) с сохранением подкаталогов. Нужны в том числе `app.py`, `engine.py`, `static/`, `packaging/`, `installer/`, `tests/`, `release_config.py`. Не загружайте демонстрационные скриншоты, `__pycache__`, `.test_data`, `*.sqlite3`, токены или пароли. `README.md` и `.github/workflows/windows-release.yml` уже есть — их можно пропустить.
4. Сохраните коммит, убедитесь, что файлы видны в корне.
5. Откройте [GitHub Actions](https://github.com/kazakavtobus/void-leads/actions/workflows/windows-release.yml), выберите **Run workflow** (ветка main). Workflow проверит код, соберёт EXE на Windows, упакует установщик и опубликует релиз v0.4.0.
6. После успешного завершения установщик будет доступен в [Releases](https://github.com/kazakavtobus/void-leads/releases).

## Безопасность

Не загружайте клиентские базы, пароли и VK-токены. Данные установленной программы хранятся локально в `%USERPROFILE%\\VOID-LEADS`. Установщик пока **не подписан**; Windows SmartScreen может показать предупреждение. Не отключайте систему защиты, проверяйте источник скачивания и SHA-256.

## Обновления

Когда первый выпуск установлен и канал релизов работает, следующую версию публикуют новым тегом `v0.4.1`. Проверка обновлений в программе сравнивает доступный GitHub Release с текущей версией, скачивает установщик и проверяет контрольную сумму.
